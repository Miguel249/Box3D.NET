The Box3D.NET.Native package ships compiled Box3D binaries -- box3d.dll,
libbox3d.so and libbox3d.dylib, one per supported platform. They are built from
unmodified Box3D sources, consumed as a pinned git submodule. No Box3D source
file is altered, vendored or relicensed by this project.

The declarations in Box3D.NET.Native are generated from the Box3D headers and
carry Box3D's own documentation comments, so parts of that documentation are
reproduced in this package's XML documentation files.
