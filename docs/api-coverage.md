`NATIVE_ONLY` is not a to-do list. Most of it is machinery an idiomatic API
should not surface: individual accessors that a single property reads several
of at once, recording and replay, tree internals, and the profiling and
counter functions. The escape hatch in `Box3D.Interop` exists so that needing
one of them is an inconvenience rather than a wall.
